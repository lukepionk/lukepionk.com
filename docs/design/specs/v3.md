# Website v3: content first

Status: implemented locally September 28, 2026. Supersedes the visual
direction in [v2](v2.md); the five-section structure is unchanged.

## Why

Luke wanted the page to feel simple, sleek, and conservative, so readers are
impressed by the content rather than the design. The v2 design gave the most
visual weight to the least important elements: a decorative mug panel, four
section backgrounds, pastel cards, and a mock browser window.

## Decisions

- One ivory background, near-black text, and green only for links and focus.
- One left-aligned text column (42rem) on every screen size, so desktop,
  tablet, and phone share a single layout.
- Ordinary heading sizes; sections separated by space and a thin rule.
- Hero: city, what Luke builds, a short paragraph, a now/before line, and
  email, LinkedIn, and GitHub so contact is visible before scrolling on a phone.
- Lessons, the project, and resources are plain text blocks and lists, not
  cards. The project block repeats when a second project is added.
- The release path stays as a plain list. It links to the real script instead
  of showing hashes or file counts that would go stale.
- No headshot for now. If one is added later, it belongs near Contact, and the
  publish allowlist and tests must change deliberately.

## Checks

Browser tests cover 320, 390, 720, 768, 1024, and desktop widths for overflow,
accessibility at phone and tablet sizes, and 44px tap targets for the hero and
contact links.
