Now

Lessons from shipping.
September 2026

  • Choose the smallest sufficient stack. For this one-page site, plain HTML and CSS make the code easier to inspect, operate, and change.
  • Put accessibility in the normal test path. The browser checks cover keyboard navigation, narrow screens, semantic structure, and automated accessibility rules.
  • Verify the artifact, not just the command. The release script checks the exact commit and confirms every uploaded file by SHA-256.
  • Know what automation cannot answer. The next useful test is human: can a stranger explain what I build after seeing this page for 30 seconds?
